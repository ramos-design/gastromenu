# **App Name**: GastroDashboard

## Core Features:

- Dashboard Overview: Displays key metrics, including the number of dishes, soups, main courses, and allergens.
- Food Management: Enables adding, editing, and deleting food items with details like CZ/EN names, type, price, and allergens, all managed in the UI state.
- Allergen Management: Facilitates adding, editing, and deleting allergens with unique IDs and CZ/EN names, while also simulating warnings for allergens in use, within the UI.
- Weekly Menu Builder: Allows users to create weekly menus by selecting soups and main courses from available dishes, with a simulated saving toast and a CZ/EN preview.
- Printable Menu Generation: Simulates the generation of a printable menu, offering a fake PDF preview and a download button for a non-functional PDF file.
- Social Post Generation: Simulates generating social media posts for CZ and EN, providing image placeholders with download buttons that do not lead to actual files.
- Website Upload Simulation: Simulates sending the menu to a website, displaying a success message and a dummy URL link or modal placeholder.

## Style Guidelines:

- Primary color: Light, desaturated blue (#A0C4FF) to create a calming and professional feel appropriate for a dashboard.
- Background color: Very light desaturated blue (#F0F8FF) for a subtle and clean glassmorphism effect.
- Accent color: Soft lavender (#BDB2FF) to provide contrast and highlight key interactive elements.
- Body and headline font: 'Inter' for a modern and clean sans-serif typeface suitable for both headers and body text.
- Use simple, outlined icons to maintain a modern and uncluttered look.
- Employ a desktop-first, responsive layout with a sidebar, topbar, and clear content divisions using cards and tables. Glassmorphism effects should be consistently applied to cards and modals.
- Incorporate subtle hover effects, transitions, and loading animations to enhance user interaction and provide feedback during simulated data processing.
